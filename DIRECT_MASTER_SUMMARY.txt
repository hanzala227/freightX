┌───────────────────────────────────────────────────────────────────────────┐
│  WHAT WAS IMPLEMENTED                                                     │
└───────────────────────────────────────────────────────────────────────────┘

  When "Direct Master" checkbox is CHECKED, a special section appears with:

  ✅  Customer          (Select dropdown)
  ✅  Shipper           (Select dropdown)
  ✅  Consignee         (Select dropdown)
  ✅  Notify            (Select dropdown)
  ✅  Bill To           (Select dropdown)
  ✅  Sales             (Select dropdown - Users)
  ✅  Sales Type        (Select dropdown - NOMINATED, FREE HAND, DIRECT)


┌───────────────────────────────────────────────────────────────────────────┐
│  HOW IT WORKS                                                             │
└───────────────────────────────────────────────────────────────────────────┘

  1. User checks "Direct Master" checkbox
     
  2. Blue section appears immediately with 7 fields
     ┌─────────────────────────────────────────────────────────┐
     │ 📋 Direct Master Information                            │
     ├─────────────────────────────────────────────────────────┤
     │  [Customer ▼]  [Consignee ▼]  [Bill To ▼]  [Sales Type] │
     │  [Shipper  ▼]  [Notify    ▼]  [Sales   ▼]               │
     └─────────────────────────────────────────────────────────┘
  
  3. User fills in the fields (all optional)
  
  4. User saves the form
  
  5. All data persists to database
  
  6. On edit, section shows if checkbox was checked


┌───────────────────────────────────────────────────────────────────────────┐
│  UI DESIGN                                                                │

  Border:         Blue (#4b77be, 2px solid)
  Header:         Blue with icon
  Layout:         4-column grid
  Animation:      Smooth show/hide
  Visibility:     Hidden when checkbox unchecked

│  TECHNICAL DETAILS                                                        │
└───────────────────────────────────────────────────────────────────────────┘

  Technology:     Alpine.js x-show directive
  State Variable: isDirectMaster (boolean)
  Binding:        x-model="isDirectMaster"
  
  Database Fields:
    • is_direct_master      (BOOLEAN)
    • dm_customer_id        (FK to trade_partners)
    • dm_shipper_id         (FK to trade_partners)
    • dm_consignee_id       (FK to trade_partners)
    • dm_notify_id          (FK to trade_partners)
    • dm_bill_to_id         (FK to trade_partners)
    • dm_sales_person_id    (FK to users)
    • dm_sales_type         (VARCHAR)

  File Modified:
    resources/views/air-import/index.blade.php


┌───────────────────────────────────────────────────────────────────────────┐
│  DATA FLOW                                                                │
└───────────────────────────────────────────────────────────────────────────┘

  CREATE MODE:
  1. User checks checkbox → isDirectMaster = true
  2. Section appears with empty fields
  3. User fills fields
  4. Form submits to store() method
  5. Controller saves all dm_* fields
  6. Success!

  EDIT MODE:
  1. Load shipment from database
  2. If is_direct_master = true → isDirectMaster = true
  3. Checkbox is checked
  4. Section is visible
  5. Fields populated with saved values
  6. User can modify and save
